# Условия публичного выпуска

Код не заменяет внешнюю приёмку. Локальные этапы 7–18 и результаты проверок перечислены в implementation-progress.md. Эта таблица отделяет готовые компоненты от настроек, которые нельзя достоверно выбрать за оператора.

| Условие | Состояние | Что необходимо |
|---|---|---|
| Финансовый учёт и разграничение доступа | Проверены автотестами | Пользовательская приёмка собственных сценариев |
| Google Sheets | Код и тесты готовы | Файл service-account JSON, доступ к нужной таблице, реальный экспорт |
| Stars, подписка, квоты | Код и тесты готовы; оплата выключена | ID владельца, цена, квоты, условия; внешняя проверка покупки, продления, отмены и возврата |
| Панель | Код, HTTP-тесты и визуальная проверка готовы; доступ выключен | ID владельца, TOTP, HTTPS-домен |
| Политика обработки данных | Механизм согласия/удаления готов | Оператор и страна хранения, опубликованные URL, срок платёжных записей |
| Распознавание | Модульные тесты и небольшой синтетический прогон настоящего API | Размеченный независимый набор чеков/голоса, замер точности и задержек |
| Резервный AI-провайдер | Не подключён | Выбор провайдера, ключ, бюджет, обновление согласия пользователей |
| Внутренняя очередь | Конкурентность и аварийное восстановление проверены | Повтор нагрузки на выбранном сервере с настоящим AI и Telegram |
| Постоянный сервер | Конфигурации и инструкции готовы | Сервер/регион/домен, TLS, лимиты и канал алертов |
| Резервирование | Локальная шифрованная копия и восстановление проверены | Таймер, независимое хранилище копий и актуального реестра, отдельное хранение ключа |
| RPO/RTO и доступность | Цели описаны, локальная проверка выполнена | Подтвердить RPO ≤ 1 ч, RTO ≤ 4 ч и доступность 99,5% на постоянной инфраструктуре |
| Docker | Compose валиден | Запустить Docker daemon, собрать и проверить образ на целевой архитектуре |

Внешние сервисы: Telegram (сообщения/файлы/Stars), OpenAI (голос и изображения — без отдельного разрешения, обработка включена по умолчанию; категоризация текста и анализ отчётов — по настройкам соответствующих функций), Google Sheets (после подключения), PostgreSQL и приватное файловое хранилище. В текущей локальной установке данные хранятся на компьютере пользователя; страна будущего сервера ещё не утверждена.

Стоимость не объявляется без тарифа и объёма. Для планирования использовать фактическое число текстовых запросов, минут голоса, файлов/страниц, входных/выходных токенов, объём оригиналов и резервных копий. Панель показывает токены и настраиваемую оценку затрат, которая не является счётом провайдера. Лимиты AI задаются оператором; нагрузочный тест со заглушками не расходует AI API.
