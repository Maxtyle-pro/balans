# Автоматическая запись операций

Настройка `user_settings.automatic_capture` включена по умолчанию после миграции 025. В настройках можно вернуться к подтверждению каждой записи. Ручной ввод сохраняет прежнее явное подтверждение.

Распознанные расходы из текста, голоса, фото и PDF записываются автоматически. Личные доходы из текста и изображений также записываются автоматически; голосовой ввод пока поддерживает один расход. Карточка содержит заголовок, описание, сумму, категорию и дату с эмодзи, без названий полей, и единственную кнопку «✏️ Изменить». Для нескольких операций отправляется отдельная карточка на каждую запись. Кнопка открывает изменение конкретной операции с явным сохранением новой версии.

Неопределённая категория — «⚠️ Без категории». Если описание отсутствует, показывается «⚠️ Без описания». Если дата не определена, в учёте используется дата исходного сообщения в часовом поясе пользователя, а карточка явно показывает «⚠️ ДД.ММ.ГГГГ · дата сообщения». Признаки неопределённости сохраняются в версиях операций; редактирование даты или описания снимает соответствующий признак. История отмечает такие записи предупреждением.

Без суммы запись не проводится. Неясный статус оплаты чека требует ответа пользователя. Явная другая валюта не переименовывается и не конвертируется автоматически. Возвраты, переводы и совместные приходы сохраняют прежние проверки и сверку. Ошибка категории допускает запись без категории; ошибка распознавания суммы — нет.

Повтор Telegram update возвращает сохранённый ответ. Повторная загрузка идентичного файла чека возвращает прежнюю запись без нового расхода. Разные покупки одной суммы и даты допускаются. Это точное сравнение содержимого файлов, а не поиск визуально похожих фотографий.

Проверки: tests/test_automatic_capture.py. Legacy-тесты используют режим подтверждения; тестовая фикстура отдельно проверяет, что миграция устанавливает default true. Новые тесты явно включают производственный режим через кнопку настроек.

Изменения подготовлены локально. Деплой не выполнялся.
