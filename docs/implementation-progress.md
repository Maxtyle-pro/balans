Уточнение требований к распознаванию: голос, чеки, скриншоты и фото обрабатываются без отдельного разрешения пользователя; каналы включены по умолчанию. Проверка версии согласия на изображения удалена. Ручное отключение и включение доступны через `/voice off|on` и `/receipts off|on`; проверка карточки перед сохранением сохранена. Изменение реализовано, миграция 019 применена к локальной базе, 221 тест прошёл. ТЗ, архитектура, модель данных и инструкции обновлены.

Карточки ввода показывают описание или позиции, сумму, категорию и дату, без бюджета, счёта, часового пояса, пояснения об источнике даты и статуса «Пока не сохранён». Голос выдаёт результат без промежуточного сообщения. Изображения распознаются автоматически; страницы Telegram-альбома собираются перед одним запросом. При нескольких позициях доступны «Разбить по категориям» и «Выбрать другую категорию». Разбиение предлагает категории товаров и показывает суммы по категориям; неполный перечень и расхождение с итогом блокируют разбиение. В отчёты входят только подтверждённые части, без общего расхода поверх них; исходные документы остаются прикреплёнными.

Проверка упрощённого ввода: 330 тестов, включая автоматический OCR, сбор Telegram-альбома, разбиение с точным итогом, смену категорий, устаревшие кнопки, защиту от повторного чека, дату отправки как запасную дату для файлов, актуальную помощь и переключение `/ai on|off`. Изменений схемы БД не требуется.

Упрощение изображений 15.09.2026: в автоматическом режиме расход с распознанной суммой сохраняется без подтверждения оплаты; pending/unknown не блокируют запись, явный failed остаётся на проверке. Строки одной покупки с одинаковой категорией, датой, валютой и счётом объединяются. После записи показывается только «✏️ Изменить». Общая регрессия — 352 теста.
